# 2026-10-29 工作日志

## 项目从 JDK 8 / Spring Boot 2.3 升级到 JDK 25 / Spring Boot 3.4

### 背景
编译报错 `java.lang.ExceptionInInitializerError` + `com.sun.tools.javac.code.TypeTag :: UNKNOWN`，
根因：机器只有 JDK 25（D:\Java\JDK），但项目声明 java.version=1.8、Spring Boot 2.3.12、Lombok 1.18.20，
老 Lombok 反射 JDK 内部 TypeTag 枚举在 JDK 25 下崩溃。用户选择继续用 JDK 25，遂整体升级。

### 改动清单
1. pom.xml
   - Spring Boot 2.3.12.RELEASE -> 3.4.5
   - java.version 1.8 -> 21（maven.compiler.source/target 同步 21）
   - lombok 1.18.36 -> 1.18.38
   - mysql-connector-java 5.1.47 -> 8.0.33
   - mybatis-plus-boot-starter 3.4.3 -> mybatis-plus-spring-boot3-starter 3.5.12
   - hutool 5.7.17 -> 5.8.38
   - 新增 mybatis-plus-jsqlparser 3.5.12（分页插件 PaginationInnerInterceptor 必需）
   - 新增 maven-compiler-plugin 3.13.0 + annotationProcessorPaths 显式声明 lombok
     （关键：否则 JDK21+ 下 Maven 编译不启用 Lombok 注解处理器，getter/setter/log 全部找不到）
2. application.yaml
   - datasource.driver-class-name: com.mysql.jdbc.Driver -> com.mysql.cj.jdbc.Driver
   - url 加 allowPublicKeyRetrieval=true
   - spring.redis.* -> spring.data.redis.*（Spring Boot 3 配置路径变更）
3. 代码 javax -> jakarta（Spring Boot 3 迁移）
   - 6 个文件 import javax.annotation.Resource -> jakarta.annotation.Resource
   - UserController import javax.servlet.http.HttpSession -> jakarta.servlet.http.HttpSession

### 验证
- mvn clean compile / package 均成功，生成 target/hm-dianping-0.0.1-SNAPSHOT.jar（41MB）
- 运行期未验证（需 MySQL 127.0.0.1:3306/hmdp + Redis 192.168.100.128:6379）

### 遗留注意
- IDE 项目 SDK 仍为 JDK 25（.idea/misc.xml project-jdk-name="25"），与 source/target=21 并存可编译，
  但建议在 IDEA Project Structure 里把 Language level 设为 21，避免 IDE 与 Maven 编译结果不一致。
- 后续若继续升级，可考虑直接 java.version=25。
